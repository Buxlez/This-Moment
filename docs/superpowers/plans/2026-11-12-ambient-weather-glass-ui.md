## 1. 目标

1. **背景**：用全屏动态天气场景替换现在的浅紫渐变，主视觉是「隔着车窗玻璃看外面」。
2. **6 个预置场景**，每个对应一种天气和一个时段；外加一个 **随机切换** 按钮。用户不再手动填城市、天气和时间。
3. **中间玻璃面板就是 agent 对话框**：标题、环境信息、对话流、生成进度、输入框、播放器都放在这一块磨砂玻璃里。
4. 现有功能一个不少：推荐卡片、生成进度、TTS 叙述、全局播放器、历史恢复、提示消息。

## 2. 六个场景

场景同时决定 **推荐用的环境数据**（城市、天气、时间，发给后端）和 **背景视觉参数**。6 个场景刚好覆盖后端天气枚举里除「未知」以外的 6 种：晴朗、多云、下雨、高温、寒冷、雪天。

## 3. 布局

```
┌───────────────────────────── 全屏 <canvas> 天气场景 ─────────────────────────────┐
│                                                                          ( ⌂ )   │
│        ┌──────────────── 玻璃面板 .glass-panel ────────────────┐         ( ◎ )   │
│        │                 THIS MOMENT                          │         ( ⚄ )   │
│        │          ● 深圳 · 下雨 · 21:00                        │         ( ◐ )   │
│        │ ──────────────────────────────────────────────────── │                 │
│        │  对话流（推荐卡片 / 生成进度），在面板内部滚动         │                 │
│        │                                                      │                 │
│        │  [ 说说此刻的感受和想听的风格吧 …………………… ↑ ]          │                 │
│        │  ▣ 歌名·歌手   ⏮ ▶ ⏭   ──●────  1/8  🔈             │                 │
│        └──────────────────────────────────────────────────────┘                 │
└──────────────────────────────────────────────────────────────────────────────────┘
```

- **玻璃面板**：水平居中，`width: min(880px, 100% - 2*gutter)`，高度 `calc(100dvh - 2*gutter)`。样式是 `backdrop-filter: blur(18px) saturate(1.2)`、半透明深色底 `rgba(8,12,18,.38)`、1px 发丝边框 `rgba(255,255,255,.08)`、内阴影做出玻璃厚度、圆角 `--panel-radius: 4px`（参考站几乎是直角）。
- **面板头部**：
  - 标题 `THIS MOMENT`，用等宽字体、大写、拉开字距。
  - 下面一行状态：绿色圆点表示音源状态，原来的 `#modePill` 并到这里；接着是 `城市 · 天气 · 时间`，等宽字体，颜色用场景主色。
- **对话流**：不再用白色卡片。每条推荐是一行，用发丝线分隔：
  - 用户原话：右对齐，小号，透明度约 0.6；
  - 曲目：56px 封面、歌名、歌手；
  - 推荐理由：无衬线体，15px，行高 1.7，透明度 0.78（D3）；
  - 当前播放的那一行左侧加一条场景主色竖线（`.is-current`）。
- **生成进度**：一条 2px 细线，下面是 `理解 · 候选 · 核对 · 整理` 四个等宽字体的步骤，当前步骤用场景主色高亮。
- **面板底部**：
  - 第一行是输入框：透明底，聚焦时只亮底边线，发送按钮是圆形描边。
  - 第二行是播放器：左边封面、歌名和播放控制；中间是进度条，已播部分用短粗的主色线，呼应参考站中间那根绿色短线；右边是队列位置和静音。
  - 最底下是 AI 免责小字，等宽，透明度 0.4。
- **右侧按钮栏**（固定在右边，56px 圆形按钮，深色半透明，发丝边框）：
  1. `⌂` 回到对话顶部；
  2. `◎` 场景面板：弹出一个浮层，2×3 排列 6 个场景缩略图（缩略图用该场景的 CSS 渐变兜底样式，不用另开 WebGL），每张写名称和「城市·天气·时间」；最后一行是「用此刻真实天气」（见 D1）；
  3. `⚄` 随机切换；
  4. `◐` 沉浸模式：玻璃面板淡出，只看背景；再点一次或按 Esc 恢复。
- **≤1024px（平板、手机）**：面板贴满整个视口，四周留 16px；右侧按钮栏改成面板头部右上角的一排小图标；场景浮层改成底部抽屉。

### 3.1 主页面文案（D6）

- **删掉**旧的引导区：「AI 推荐」小标签、标题「把此刻，翻译成一组歌」和副标题「说感受、场景或你想要的状态，一句话就够了」，也就是 `index.html` 里整个 `section.conversation-intro`。面板头部的 `THIS MOMENT` 和环境状态行已经起到标题的作用。
- **空状态**（`#emptyState`）放在对话流中间，在玻璃面板里垂直居中：
  - 主句**保留**：「从一句模糊的想法开始」。
  - 副句表达的意思最重要：**你说的话决定推荐什么，天气和时间只是参考**。旧版写的「时间与天气只是背景，你的原话永远最重要」太抽象，先换成下面的默认文案，用户之后可能还会改：
    - **默认：「窗外的天气和时间只作参考，你说的那句话才算数。」**
    - 候选 1：「天气和时间我们帮你记着，你只管说想听什么。」
    - 候选 2：「不管窗外是什么天气，最后听什么，由你那句话决定。」
    - 候选 3：「环境只是参考，你说的感受才是答案。」
  - 文案要集中写在 `index.html` 的一个地方，方便以后改，不要散落在 JS 里拼接。
  - 下面三个示例按钮（`.prompt-chips`）保留，换成玻璃风格。
- 输入框 placeholder 默认是「说说此刻的感受和想听的风格吧」；按 D2 的规则，用户已经输入过文字时，placeholder 换成当前场景的示例句。

### 视觉规范

- 只做深色主题。文字颜色 `rgba(255,255,255,.9)`，次级文字 `.6`，弱化文字 `.4`。
- 场景主色通过 CSS 变量注入：JS 切换场景时设置 `document.documentElement.style.setProperty('--scene-accent', …)`，同时设置 `--scene-accent-soft`。状态圆点固定用绿色 `#22c55e` 系。
- 字体：
  - 界面文字和推荐理由：`Inter, "PingFang SC", "Noto Sans SC", system-ui, sans-serif`（全部无衬线，D3）；
  - 元信息：`"IBM Plex Mono", "SF Mono", Menlo, monospace`；
  - 字体文件不走外部 CDN（车机演示时可能离线），只用系统字体栈，没有就直接回退。
- 动效：场景切换 900ms；面板淡入淡出 240ms；新卡片出现时 8px 上移加淡入。开启 `prefers-reduced-motion` 时全部关掉，背景只渲染一帧静态画面。

## 4. 背景渲染器

### 4.1 版权约束（必须遵守）

参考站的雨滴效果来自 Shadertoy 上的《Heartfelt》，许可协议是 CC BY-NC-SA，**不能把它或参考站的代码移植、改写过来**。必须自己写着色器。雨滴折射用的是公开的通用技术（网格化水滴、按水滴形状算法线、按法线偏移采样坐标），可以按原理自己实现。

### 4.2 结构

新增 `pwa/scene-renderer.js`，用原生 WebGL2，不引入任何第三方库：

```js
const renderer = createSceneRenderer(canvas, { dprCap: 1 });
renderer.setScene(sceneVisual, { transitionMs: 900 }); // 交叉淡化
renderer.setPointer(x, y, active);                     // 只有 cold-dawn 用
renderer.setPaused(true|false);                        // 页面隐藏、沉浸模式之外不用停
renderer.destroy();
// 不支持 WebGL2 时返回 null，调用方改用 CSS 兜底背景
```

渲染分两个 pass：

1. **底图 pass**，渲染到半分辨率的 FBO：
   - 用域扭曲 fbm 做双色流体（`colorA`、`colorB`）；
   - 叠加 N 个缓慢漂移的柔光斑（bokeh），模拟窗外的城市灯光，颜色取自 `bokehColors`；
   - 加上该场景专属的底层元素：晴天的光束、多云的云影、高温的眩光。
2. **合成 pass**，全屏绘制：
   - 对底图做模糊采样（降采样后多点采样即可），模拟隔着玻璃看出去的虚化；
   - 叠加天气层，按 `weather` 分支：
     - `rain`：静止小水珠网格，加上带水痕的下滑大雨滴；按水滴形状算法线，在水滴范围内用**清晰的**底图按法线偏移采样，水滴之外用**模糊的**底图；
     - `snow`：三层不同速度、不同大小的雪花，加上边缘噪声阈值形成的霜；
     - `fog`：整屏雾化加一张擦除痕迹纹理（ping-pong FBO，鼠标位置写入，每帧衰减）；
     - `heat`：画面下部的 UV 正弦扰动，表现热浪；
     - `clear`：浮尘粒子；
     - `cloudy`：不加天气层；
   - 最后做调色：暗角、颗粒噪点、场景色调。

### 4.3 场景视觉参数

放在 `pwa/scenes.js`，纯数据，并沿用 `pwa/app-model.js` 的导出方式，让 node 测试也能 require：

```js
{
  id: 'rain-night',
  visual: {
    weather: 'rain',            // rain | snow | fog | heat | clear | cloudy
    colorA: [0.02, 0.10, 0.16], colorB: [0.05, 0.25, 0.40],
    bokehColors: [[1.0, 0.35, 0.1], [0.2, 0.55, 1.0]],
    blur: 0.8, intensity: 0.7, grain: 0.06, vignette: 0.5,
    accent: '#38bdf8',          // 写入 --scene-accent
    fallbackCss: 'radial-gradient(...), linear-gradient(...)', // 不支持 WebGL 时和缩略图都用它
  },
}
```

另外导出 `pickRandomScene(currentId, rng = Math.random)`，保证返回的场景一定和当前不同。

### 4.4 性能和兜底

- 设备像素比上限是 1，底图只渲染半分辨率；`document.hidden` 时暂停 rAF。
- 帧耗时连续超过 24ms 时自动降一档：减少雨滴层数、降低分辨率。
- 不支持 WebGL2、着色器编译失败、开启了 `prefers-reduced-motion` 时：不要 canvas，给 `body` 设置场景的 `fallbackCss` 背景。
- `backdrop-filter` 的开销比较大；不支持的浏览器给面板换更不透明的底色 `rgba(8,12,18,.82)`，用 `@supports` 判断。

## 5. 数据和接口

- `server.js` 的 `PRESETS` 换成第 2 节的 6 条，字段保持 `{ id, label, icon, city, weather, hour, prompt }`，再加一个 `minute` 字段（`cloudy-dusk` 是 17:30，`cold-dawn` 是 6:30）。`localTimeForHour` 要支持分钟，`/api/environment-presets` 的返回结构不变。
- 视觉参数只放在前端的 `pwa/scenes.js`，按 `id` 和后端预设对应。如果后端没返回某个 id，前端用 `rain-night` 的视觉参数兜底。
- `app.js` 里的 `environment()` 改成从「当前场景」取 `city / weather / localTime`，`source` 用 `'preset'`；如果用了真实天气（D1），保持原来的 `'auto'`、`'manual'` 语义。发给 `/api/recommendations` 的 body 结构不变。
- 当前场景 id 存进 `localStorage('tm.scene')`，读写都包 try/catch，刷新后恢复。
