# 零跑车主演示品味设计

**日期：**2026-08-13

**状态：**已确认，待实施

## 目标

将 `user/taste.md` 调整为适用于标准 PRD 演示的零跑车主样本。核心听感是“热闹、好唱、车内有气氛”：旋律直接、节奏鲜明、具有容易记住和跟唱的副歌，同时避免把车主刻画成单一年龄、性别、家庭结构或固定审美群体。

## 默认选曲倾向

- 约 60% 使用热闹、提神、适合跟唱的中高能量歌曲，约 40% 使用舒缓或中等能量歌曲，比例只是软倾向。
- 曲风覆盖华语流行、流行摇滚、经典金曲、轻电子、R&B、说唱、欧美及日韩热门歌曲、影视与游戏 OST。
- 熟悉歌曲与新歌并存，不让推荐全部落在热榜或小众音乐。
- 通勤、朋友同行和周末出游可加强节奏与车内气氛；夜间、堵车或用户明确要求放松时降低能量。

## 约束

- 用户本轮明确要求始终高于默认画像、场景和语言比例。
- “闹一点”解释为热闹、好唱、有强副歌，不默认等同于高响度、重低音或持续强刺激。
- 避免连续多首高密度歌曲、短视频热歌堆叠、刻板“土嗨”以及同一卡片歌手过度集中。
- 不通过天气机械推断情绪，不宣称该配置代表所有零跑车主。

## 修改范围与验收

本轮仅重写 `user/taste.md`，不修改推荐算法和 Prompt 拼装逻辑。完成后检查 Markdown 内容、Git 差异以及现有文档所描述的软偏好边界，确保配置仍然只提供默认倾向，不覆盖用户当次输入。
